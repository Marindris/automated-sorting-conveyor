# Mini Automated Sorting Conveyor

## Project Status
🚧 In Development

## Overview
A miniature automated sorting conveyor developed as a hands-on industrial automation portfolio project.

The project will be developed progressively, beginning with PLC control simulation and later incorporating sensors, motor control, HMI, fault handling, industrial communications, testing, and documentation.

## Objectives

- Learn and demonstrate PLC programming fundamentals
- Develop PLC-style sequential control logic
- Implement sensor and actuator control
- Develop an HMI for operation and monitoring
- Implement alarms, interlocks, and fault handling
- Learn industrial communication protocols
- Apply FAT/SAT and commissioning practices
- Document the complete engineering process

## Planned Development

- PLC architecture
- Digital inputs and outputs

### Phase 7 — Testing and Documentation
